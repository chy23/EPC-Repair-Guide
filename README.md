# 麗園國小常見電腦問題指南 (EPC-Repair-Guide)

> **新北市林口區麗園國民小學** 教學設備與常見電腦問題排查手冊  
> 專為校園教師與同仁設計，以**手機瀏覽為主要載具**，提供快速排查、步驟圖解與一鍵報修引導。

---

## 🌟 網站特色

1. **手機優先體驗 (Mobile-First) 與分層式導航架構**
   - 專為智慧型手機直立閱讀優化，排版乾淨、點擊目標適中、響應式動態版面。
   - **全新分層跳轉設計**：非傳統單頁長卷軸手風琴堆疊，而是採清晰的 3 層次導航：
     - **第 1 層 (封面)**：點擊空白處進入大項目。
     - **第 2 層 (大項目列表)**：呈現四大核心分類，點擊大項後進入該分類的專屬問題清單。
     - **第 3 層 (細項問題清單)**：僅呈現該大類的題目列表，點擊題目後進入獨立詳解。
     - **第 4 層 (題目與解法詳解頁)**：單一獨立頁面專注呈現該問題的題目、成因、步驟圖解，支援「上一題/下一題」與麵包屑返回。
3. **四大核心分類與圖解指南**
   - **一、班級電腦硬體與設備問題**：
     - 開機畫面黑底白字排查（主機久未供電成因）。
     - **N4660 主機 BIOS 7 大設定步驟**（附完整步驟高解析截圖、關鍵字高亮、點擊放大燈箱與完整原圖對照）。
     - 大屏觸控故障不靈敏（粉筆灰擦拭清潔與 Touch USB 線重插排查）。
   - **二、網路連線問題**：
     - 加入學校無線網路 `eduroam` 教學（帳號密碼規則、無須登記 MAC Address、跨校漫遊）。
   - **三、校務系統與帳號密碼問題**：
     - 親師生平台學生帳號密碼導師還原方式與三選一規則。
     - 學生預設密碼逾期未修改（3日內限制）之解法與注意事項。
     - 忘記密碼還原對象矩陣（教職員工洽資訊組、志工洽承辦人、家長與學生洽導師）。
     - 為何無法執行忘記密碼成因分析（需驗證備用信箱或手機）。
     - 單一簽入 (SSO) 入口與校務行政系統 (`esa.ntpc.edu.tw`) 對照。
     - 備用信箱及行動電話驗證步驟指引與官方截圖。
   - **四、雙因子驗證問題（針對非學生身分：教職員工、志工、家長）**：
     - 校園通 APP 雙因子驗證方式說明（限簡訊與 Email）。
     - 未驗證信箱與手機時的 3 次「直接登入」機會利用教學。
     - 3 次直接登入機會耗盡後之還原重計機制。
     - 「信任此裝置30天」勾選設定與 4 大資安注意事項（公用電腦勿勾選等）。
4. **即時關鍵字搜尋**
   - 支援即時輸入過濾（例如輸入「BIOS」、「eduroam」、「忘記密碼」、「3次」、「粉筆灰」），瞬間定位解法。
5. **圖片高解析度放大燈箱 (Lightbox)**
   - 所有步驟配圖點擊皆可進入全螢幕燈箱，支援放大、縮小、平移，方便手機上辨識 BIOS 藍色畫面設定細節。
6. **線上報修直達連結**
   - 內建報修專區彈窗，整合麗園國小專屬線上報修系統連結 (`schno=014793`) 與報修前檢查清單。
7. **離線支援 (PWA & Service Worker)**
   - 內建離線快取機制，即使班級網路或 Wi-Fi 異常中斷，手機已載入的手冊依然能離線完整閱讀。
8. **GitHub Actions 自動部署**
   - 提交更新推送到 `main` 分支後，自動由 GitHub Actions 建置並發佈至 GitHub Pages。

## 🚀 GitHub Pages 自動部署說明

本專案已配置繁瑣度為零的自動化工作流程檔 `.github/workflows/deploy.yml`。

### 啟用步驟：
1. 進入 GitHub 專案倉庫：[chy23/EPC-Repair-Guide](https://github.com/chy23/EPC-Repair-Guide)
2. 點選倉庫上方的 **Settings** ➔ 左側選單的 **Pages**。
3. 在 **Build and deployment** 區塊：
   - **Source** 下拉選單選擇 **GitHub Actions**。
4. 每次 `git push` 至 `main` 分支，GitHub Actions 將會自動執行並部署網站。
5. 部署完成後，網站網址將為：  
   `https://chy23.github.io/EPC-Repair-Guide/`

## 🛠️ 後續內容維護與擴充指南

若未來需要新增常見問題或修改報修連結，**僅需編輯 `js/data.js`**：
- 新增/修改問題：在 `GUIDE_DATA` 相對應的大項目中加入新題目物件。
- 修改報修網址：更新 `REPAIR_INFO` 物件中的 `onlineFormUrl` 網址。
- 修改後只要 `git commit` 並 `git push`，GitHub Pages 便會在 1 分鐘內自動完成更新發佈！
